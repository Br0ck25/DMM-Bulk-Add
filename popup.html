DMM Bulk Add

Select-all checkboxes for list pages, so you can send many titles to Debrid Media Manager at once instead of one by one.

Titles sent so far: 0
"Use one shared tab" reuses a single tab for the whole batch instead of opening one tab per title — same result, no tab-bar clutter.
On each DMM page, if a cached ("Instant RD") result is found it's clicked automatically once the results list stops changing. If nothing is cached, the tab/page is left as-is so you can pick "DL with RD" manually.
Works on: IMDb, MDBList, Trakt, TMDB, TheTVDB and Letterboxd list/watchlist pages.
